# Implementation-of-Gauss-Methods-in-Python

This project implements three methods for solving systems of linear equations:

- Gaussian elimination without pivoting
- Gaussian elimination with partial pivoting
- Gaussian elimination with total pivoting

## Language
Python

## How to run

Run the following command in the terminal:
```bash
python main.py
```

## Example
The program solves a system of three linear equations and displays the solution using the three methods.
